# Public release checklist

- [ ] Both authors approve public release and accurate attribution.
- [ ] Confirm MIT rights for every source file.
- [ ] Review code and results for secrets, credentials, employer/customer identifiers, and proprietary information.
- [ ] Independently execute diagnostic and full run in Ubuntu/Mininet VM.
- [ ] Investigate any throughput values inconsistent with the nominal 10 Mbit/s bottleneck.
- [ ] Verify trial counts, labels, packet-loss definitions, and plotted statistics.
- [ ] Confirm journal/preprint sharing policies before posting a manuscript PDF.
- [ ] Add public DOI and accurate submission/publication status only after verification.
